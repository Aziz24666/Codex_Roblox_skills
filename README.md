## Quick start
1. Download and extract the V23 release. Open the package root in Codex.
2. Read AGENTS.md and INDEX_V23.md.
3. Start substantial tasks with the roblox-end-to-end-development-orchestrator skill.
4. Inspect the game with python v18/tools/v18.py doctor --root .
5. Discover the full monetization portfolio:
   python v23/tools/v23.py discover-opportunities --root . --output reports/v23-opportunities.json
6. Audit price handling with python v22/tools/v22.py audit-pricing --root .
7. Validate subscriptions with python v22/tools/v22.py validate-subscription-contract --root . --file v22/examples/subscription-contract.example.json
8. Run python v23/tools/v23.py verify --root . and complete live Roblox Studio and Creator Dashboard checks.

## Growth principles
Maximize sustainable value and discover the widest viable portfolio—not pressure. Keep the core game fun without spending, show fixed outcomes and honest prices, improve real retention, and use aggregate analytics. Do not use gambling, paid random outcomes, artificial playtime, AFK loops, fake scarcity, forced ads, or individual-spender targeting. Separate player purchases, Creator Rewards, ads, and creator marketplace income.

## Validation boundaries
Static checks cannot inspect Creator Dashboard eligibility, prove live Marketplace behavior, execute Roblox Studio, or guarantee sales and Robux. The V23 fit score is evidence density, not predicted revenue. Mark unexecuted live checks NOT_RUN or BLOCKED.
