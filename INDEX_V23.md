# Roblox Codex Game Studio Kit — V23 Index

V23 is the current cumulative release. It extends V1–V22 with five monetization-growth specialists, a 48-route opportunity catalogue, project-wide opportunity discovery, engagement-loop guidance, and aggregate store/revenue analytics.

## Start here
1. Read AGENTS.md and this index.
2. Start substantial tasks with the roblox-end-to-end-development-orchestrator skill.
3. Inspect the project using python v18/tools/v18.py doctor --root .
4. Generate a broad monetization report: python v23/tools/v23.py discover-opportunities --root . --output reports/v23-opportunities.json
5. Generate price-readiness evidence: python v22/tools/v22.py audit-pricing --root .
6. Validate subscriptions: python v22/tools/v22.py validate-subscription-contract --root . --file <path>.
7. Run python v23/tools/v23.py verify --root . and complete live release gates.

## V23 scope
V23 grows the cumulative package to **201 native skills**. Its monetization catalogue includes in-experience Robux purchases, subscriptions, private servers, Creator Rewards, eligible immersive ads, avatar/affiliate items, and Creator Store income. All V18–V22 safety, server-authority, deterministic-fulfillment, and evidence requirements remain mandatory.

## Key interpretation
A catalogue match is an idea to investigate, not a directive to implement. Fit scores are not revenue forecasts. No paid random rewards or gambling-like systems are permitted.
