# V22 — Platform earnings and Creator Rewards

## Separate accounting streams
Do not combine unlike revenue categories into one unexplained total:
- Player purchases: passes, developer products, and subscriptions.
- Roblox-funded creator programs: Creator Rewards and currently documented reward programs.
- Advertising: only if account, experience, audience, placements, and current rules permit it.
- Creator marketplace sales: avatar items or other creator products when applicable.

Track gross sales, platform fee treatment, pending earnings, adjustments, and realized Robux separately using current dashboard evidence. Never infer reward amounts from source code, time spent, visits, or guessed conversion.

## Creator Rewards review
1. Check current official Creator Rewards documentation.
2. Check actual eligibility and available reporting in Creator Dashboard.
3. Record ownership, account standing, and applicable verification/permission prerequisites.
4. Improve the game through onboarding clarity, stability, meaningful repeatable content, cooperation, and accessibility.
5. Measure meaningful outcomes in aggregate and preserve cohort size and observation period.
6. Never simulate activity, use alternate accounts, create AFK loops, or manipulate session length to chase rewards.

Program criteria can change. A skill or source scan is not an eligibility decision.

## Portfolio selection
Record value to players, eligibility evidence, build/operations cost, policy dependencies, and accounting source. Prefer a small portfolio the team can deliver reliably over an oversized storefront.
