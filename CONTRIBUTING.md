# Contributing

- Read `AGENTS.md` and the relevant specialist skill before changing code.
- Research current official Roblox documentation for API/platform changes.
- Keep changes focused, modular, and reproducible.
- Do not commit credentials, player data, unpublished assets, or production secrets.
- Include research sources, alternatives, tests, evidence, and known limitations.
- Run the Python preflight and regression suite. Run Luau compilation and Rojo builds when available; report checks that could not be run.
- Keep generated files reproducible from their source definitions.
