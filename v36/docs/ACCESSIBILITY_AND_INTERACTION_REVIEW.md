# V36 Accessibility and Inclusive Interaction Review

V36 adds a structured review process for player-facing surfaces. It covers input navigation, text scaling, non-color cues, contrast review, captions for critical audio, and reduced-motion alternatives.

## Review process

1. Inventory screens, prompts, HUD elements, tutorials, alerts, and interaction points.
2. Record target platforms and input methods for each surface.
3. Review each accessibility capability as verified, not verified, or not applicable.
4. Record opaque evidence references to Studio/device tests; do not store player health information or personal details.
5. Fix blockers first, then warnings, and retest on actual target devices.

The V36 CLI validates and audits a project-authored JSON manifest. It does not inspect Roblox UI instances, run Studio, measure visual contrast from screenshots, or certify accessibility. Human review and device testing remain required.
