# Roblox Codex Game Studio Kit — V24 Index

V24 is the current cumulative release. It extends V1–V23 with automated portfolio ranking, Codex task generation, a 30/60/90-day roadmap, and optional comparison of sanitized aggregate metrics.

## One-command growth automation

```powershell
python v24/tools/v24.py run --root "C:\Path\To\YourGame" --output "reports\v24"
```

Optional project context and aggregate metrics are described in `v24/docs/AUTOMATED_GROWTH_PIPELINE.md` and templated in `v24/examples/`.

- `portfolio.json` and `PORTFOLIO.md`
- `ROADMAP_30_60_90.md`
- `CODEX_BACKLOG.json` and `CODEX_BACKLOG.md`

## Cumulative scope
V24 contains **205 native skills** and inherits V23's 48-route monetization opportunity catalogue. V18–V23 no-gambling, evidence, server-authority, player-value, and platform-monetization constraints remain mandatory.

## Automation boundary
The pipeline produces local reports and reviewable tasks only. It does not modify game source, publish products, change live prices, access Creator Dashboard, automate players, or publish experiences. Human approval and live testing are required before implementation/release.
