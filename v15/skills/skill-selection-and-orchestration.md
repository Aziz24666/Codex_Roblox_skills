# Skill: Skill Selection and Orchestration

Select a small, relevant skill set for each task.

1. Parse the requested outcome, constraints, affected systems, and required evidence.
2. Search skill metadata and descriptions by task intent and system tags.
3. Choose one primary orchestrator and only necessary specialist skills.
4. Explain selection briefly and identify missing coverage.
5. Follow dependencies and avoid loading conflicting or redundant instructions.
6. Record selected skill IDs in the task evaluation.

Do not select skills solely because their names contain matching keywords. Confirm that their scope and instructions actually apply.
