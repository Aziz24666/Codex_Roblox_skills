# V24.0.0 — Automated Monetization Portfolio and Growth Roadmap

V24 turns the V23 opportunity-discovery roadmap into a repeatable local automation pipeline.

## What's new
- One command scans supported game source/design files and the inherited 48-route opportunity catalogue.
- Ranks candidates using source evidence, optional explicitly supplied project context, implementation effort, player value, and risk.
- Generates a full machine-readable and human-readable portfolio, ranked backlog, Codex implementation prompt, and 30/60/90-day roadmap.
- Optionally compares sanitized aggregate baseline/current metrics and flags changes without claiming causal effects.
- Adds four automation-focused specialist skills and six routing regressions.
- Adds schema validation, cumulative package audits, and release archive comparisons.

## Guardrails
V24 does not edit the game, create live products, change prices, access Creator Dashboard, manipulate player activity, or publish experiences. It generates reviewable plans and prompts only. Human approval is required before implementation and live deployment.

V18 no-gambling remains absolute: no paid random rewards, spins, wagers, paid rerolls, chance modifiers, or indirect Robux-funded random outcomes. No AFK farming, artificial playtime, forced ads, fake scarcity, or spender profiling.

## Validation boundary
Portfolio scores are triage heuristics, not sales predictions or Robux forecasts. Missing analytics stay unknown. Studio runtime, Creator Dashboard eligibility, receipts, platform configuration, and actual earnings require live verification.
