# Roblox Studio Safe Edit and Review

Use this skill before applying non-trivial edits through Studio MCP or accepting code generated by another agent.

## Scope and baseline

- Identify intended project, place, Studio instance, and test universe.
- Inspect Git status and current source before changing anything.
- Record files/instances that are in scope.
- Confirm the place is isolated from production data and player state.
- If target or environment cannot be confirmed, do not write.

## Change discipline

- Prefer narrow, explainable edits over broad rewrites.
- Preserve existing APIs and data contracts unless migration is part of the approved task.
- Read every changed script back after editing.
- Inspect before/after content or available diff, then run static checks and focused tests.
- Do not delete, rename, or overwrite user-owned content without explicit approval.
- Do not silently save or publish a Studio place.

## Action approval

Require explicit approval before saving a modified open place; overwriting/deleting user-owned assets; publishing; changing production configuration; writing production DataStores or player state; changing live economy configuration; or changing player-impacting Open Cloud permissions/actions.

Before any approved persistent/production action, state the exact target, scope, likely impact, backup/rollback plan, and validation evidence. Use least privilege and a separate test environment.

## Evidence review

- Verify implementation claims against actual diffs, test output, Studio console, and screenshots.
- Record what was not tested.
- Treat an MCP success response as confirmation that the tool call completed, not proof that the feature is correct.
- Keep unit tests, Luau compilation, Rojo builds, Studio playtests, and production monitoring separate.

## Player trust

Preserve the toolkit's no-gambling policy. Do not design paid random rewards, loot boxes, gambling-like mechanics, fake scarcity, coercive purchase prompts, forced ads, AFK loops, or spender targeting. Focus on transparent, optional purchases that provide clear fixed value.
