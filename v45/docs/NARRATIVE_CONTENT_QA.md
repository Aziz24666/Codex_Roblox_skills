# Narrative content QA

Graph validity is only the first gate. Review objective clarity, narrative consistency, player comprehension, accessibility, safety, and translation context with humans.

Cover quest starts, prerequisites, objective types, branches, endings, repeat policy, and reconnect/resume. Dialogue coverage includes every line, choice destination, ending, loop, cancellation, stale choice, and unavailable actor.

Localization checks include stable text keys, placeholder consistency, translator context, text expansion, font coverage, and RTL layout. Interaction checks include touch, keyboard/gamepad navigation, text scaling, reading time, captions, and ways to dismiss optional dialogue.

Link issues to stable authored IDs and retain private-experience test evidence. Do not put player IDs, raw support conversations, credentials, or personal information in manifests.
